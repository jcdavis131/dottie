Dottie — the assistant

Dottie is the personally built, from-scratch agentic assistant of the dottie monorepo. It runs on your box, not on the web — this tab connects your browser to your local Dottie server and renders only what that server reports: real backend probes, real traces, real climb iterations. Nothing on this tab is fetched from the public internet and nothing is invented.

Run it on your box

cd ~/workspace/dottie && git pull
docker compose -f apps/dottie/docker-compose.dottie.yml up --build -d   # serves :8100
python -m dottie climb --families mixed --n 20 --backend ollama         # one measured iteration
python -m dottie climb-report                                           # table + paired verdicts

Full 4080 walkthrough (fresh mini checkpoint + Ollama brain): apps/dottie/RUNBOOK_4080.md in the monorepo.

Automated research loop

This tab renders the real experiment ledger from your local Dottie server: hypotheses ideated, code 4-level validated, a proxy micro-benchmark trained, and each result hill-climbed against the baseline. Every metric here is a real measurement; a new SOTA is declared only on a real, direction-aware improvement. Nothing on this tab is fetched from the public internet and nothing is invented. It reuses the endpoint you set on the Dottie tab.
