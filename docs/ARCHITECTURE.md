## Core Flow v0.4.1
```
User/Agent -> bb <plugin> <cmd> --json (Typer + Rich)
  -> http_utils.sanitize_no_proxy_env() [strips [] :: fd8b for hatch-egress-proxy:3128 Invalid port fix]
  -> policy.py enforce_or_raise(manifest.yaml caps, network domain)
  -> security.py vault get_secret (for auth) — tasks uses none, Hatch-managed OAuth via status/disconnect_url
  -> registry.py lookup
  -> adapter:
     openapi: fetch_spec -> parse_operations -> call_openapi OR generated plugin cli.py per-op with enforce
     mcp: list_mcp_tools_sync via sse_client -> ClientSession.list_tools()
     tasks: _run_gws([hatch_gws_cli, tasks, <resource>, <method>, --params/-json]) → emit JSON + fs write docs/llm-wiki/tasks-*.json
  -> output.py valid JSON + audit.py log → ~/.local/share/bigbang/audit.jsonl
  -> Ava: llm.py get_ollama_base() (localhost:11434, host.docker.internal:11434 2s timeout DNS-safe thread) + ollama_chat(qwen3:32b json_mode) -> route picker; fallback _heuristic_route detects task/todo/lina → tasks 0.92
  -> Agent: agent/cli.py _ollama_plan heuristic + builtin_hints task→bb tasks list etc → plan array of bb cmds checked against policy caps
  -> LLM-Wiki: docs/llm-wiki/*.md token-efficient summaries for LLMs
  -> Graphify: personal-graphify scans code+docs → graph.json → query/path/explain → copy to references/spaces/
```
